Digitale Speisekarte der Hürrem Sultan Lounge.

== Beschreibung ==

* Speisekarte als Vollbild unter /speisekarte (Adresse in den Einstellungen änderbar) – für die QR-Codes auf den Tischen.
* Menü „Speisekarte → Bearbeiten“ im Dashboard: Preise, Texte, Fotos, Allergene und Verfügbarkeit pflegen.
* Shortcode [huerrem_menu] zum Einbinden in beliebige Seiten.

Die Daten liegen in Firebase (Projekt huerrem-menu-app-1); Änderungen sind sofort sichtbar.

== Installation ==

1. Plugins → Installieren → Plugin hochladen → huerrem-menu.zip → Jetzt installieren → Aktivieren.
2. Speisekarte → Einstellungen: Adresse prüfen (Standard: /speisekarte) und speichern.
3. Speisekarte → Bearbeiten: mit dem Menü-Konto anmelden.
